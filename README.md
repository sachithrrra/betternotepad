# Better Notepad

A simple, fast plain-text editor for macOS.

## Structure

- [`app/`](app) — the macOS app (Rust, [gpui-kit](https://github.com/longbridge/gpui-kit))
- [`site/`](site) — project website

## Development

```sh
cd app
cargo run
```
